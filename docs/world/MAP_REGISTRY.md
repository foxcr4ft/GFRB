## Regras técnicas

- IDs devem ser usados como identificadores persistentes, não o nome visível.
- Nome de mapa no Roblox Studio deve corresponder ao nome oficial da coluna.
- Não renumerar mapas.
- Não usar nome de lore como chave primária.
- Faixas de nível são referência de planejamento; não codificar fórmulas de progressão com base nelas sem especificação própria.
